
## Single-line Comment

``` python
# this is a single line comment
```

## Multi-line Comment

``` python
'''
Comments are used to explain code and are ignored by the Python interpreter.

Single-line comments start with # .

Multi-line comments are enclosed in  or """ .
'''
```

## Escape Sequences

Escape sequences are used to **include special characters in strings.**

### Common escape sequences:

- \n : Newline
- \t : Tab
- \\\ : Backslash
- \\" : Double quote
- \\' : Single quote

Examples -
``` python
print("hello \n")

print("tab \they")

print("slash \\")

print("double quote \"")

print('single quote \'')

print('Hello World',"Harry",5, sep="/")

print('Hello World', end="..")

print('Harry', end="//")
```
