### Code

```python
# String

# name = "Priyam"
name = 'Priyam'
# name = '''Priyam is a good boy'''

print(name)
```

### Output

```text
Priyam
```

### Note

- A **string** is a sequence of characters enclosed in quotation marks.
- Python supports three ways to define strings:
  - **Single quotes (`' '`)**
  - **Double quotes (`" "`)**
  - **Triple quotes (`''' '''` or `""" """`)** for multi-line strings.

#### Examples

```python
name1 = "Priyam"              # Double quotes
name2 = 'Priyam'              # Single quotes
name3 = '''Priyam is a good boy'''  # Triple quotes
```

- In this program, the variable `name` stores the string `"Priyam"` using **single quotes**.
- The `print(name)` statement displays the value of the string.

**Output:**

```text
Priyam
```
