### Note

## What is a Dictionary?

A **dictionary** is a built-in Python data structure that stores data in the form of **key-value pairs**.

Each **key** is unique and is used to access its corresponding **value**.

### Syntax

```python
dictionary = {
    key1: value1,
    key2: value2,
    key3: value3
}
```

Example:

```python
marks = {
    "harry": 34,
    "jack": 45,
    "lily": 94
}
```

Here:

- `"harry"` is a **key** and `34` is its **value**.
- `"jack"` is a **key** and `45` is its **value**.
- `"lily"` is a **key** and `94` is its **value**.

---

## Dictionary Representation

```text
marks

"harry" ──► 34
"jack"  ──► 45
"lily"  ──► 94
```

---

## Accessing Values

Values are accessed using their **keys**.

```python
print(marks["lily"])
```

Python searches for the key `"lily"` and returns its value.

```text
94
```

---

## Updating a Value

```python
marks["harry"] = 3
```

Since `"harry"` already exists as a key, its value is **updated**.

Before:

```text
"harry" → 34
```

After:

```text
"harry" → 3
```

The updated dictionary becomes:

```python
{
    "harry": 3,
    "jack": 45,
    "lily": 94
}
```

Output:

```text
{'harry': 3, 'jack': 45, 'lily': 94}
```

---

## Adding a New Key-Value Pair

If the key does not exist, Python adds a new entry.

Example:

```python
marks["tom"] = 78

print(marks)
```

Output:

```text
{'harry': 3, 'jack': 45, 'lily': 94, 'tom': 78}
```

---

## Accessing a Non-Existing Key

```python
print(marks["john"])
```

Output:

```text
KeyError: 'john'
```

To avoid this error, use the `get()` method:

```python
print(marks.get("john"))
```

Output:

```text
None
```

---

## Properties of Dictionaries

- Stores data as **key-value pairs**.
- Keys must be **unique**.
- Keys must be immutable (e.g., strings, integers, tuples).
- Values can be of any data type.
- Dictionaries are **mutable**, so values can be added, updated, or removed.
- Elements are accessed using **keys**, not indexes.

---

## Dictionary vs List vs Tuple vs Set

| Feature | List | Tuple | Set | Dictionary |
|---------|------|-------|-----|------------|
| Syntax | `[]` | `()` | `{}` | `{key: value}` |
| Ordered | ✔ Yes | ✔ Yes | ✘ No | ✔ Yes (Python 3.7+) |
| Mutable | ✔ Yes | ✘ No | ✔ Yes | ✔ Yes |
| Duplicate Elements | ✔ Allowed | ✔ Allowed | ✘ Not Allowed | Keys ✘, Values ✔ |
| Access Method | Index | Index | Not Supported | Key |

## Example

```python
student = {
    "name": "Alice",
    "age": 20,
    "cgpa": 8.9

print(student["name"])
print(student["age"])
```

Output:

```text
Alice
20
```

---

## Summary

- A **dictionary** stores data in **key-value pairs**.
- Values are accessed using **keys**.
- Existing values can be updated by assigning a new value to the same key.
- Assigning a value to a new key adds a new key-value pair.
- Accessing a missing key using `[]` raises a `KeyError`; `get()` returns `None` instead.
- Dictionaries are mutable and ideal for storing related information.
