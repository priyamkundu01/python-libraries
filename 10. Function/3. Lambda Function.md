### Code

```python
# Lambda Function

square = lambda x: x * x
'''
As good as writing

def square(x):
    return x * x
'''

sum = lambda x, y: x + y
'''
As good as writing

def sum(x, y):
    return x + y
'''

print(square(3))
print(sum(3, 62))
```

### Output

```text
9
65
```

### Note

A **lambda function** is a small **anonymous (unnamed) function** in Python. It is mainly used for short, simple operations that can be written in a single line.

### Syntax

```python
lambda parameters: expression
```

- `lambda` → Keyword used to create a lambda function.
- `parameters` → Input values.
- `expression` → A single expression whose result is automatically returned.

Unlike a normal function, a lambda function:
- Does **not** use the `def` keyword.
- Does **not** require a `return` statement.
- Can contain only **one expression**.

### Example 1: Square of a Number

```python
square = lambda x: x * x
```

This is equivalent to:

```python
def square(x):
    return x * x
```

Calling:

```python
print(square(3))
```

Calculation:

```text
3 × 3 = 9
```

**Output**

```text
9
```

### Example 2: Sum of Two Numbers

```python
sum = lambda x, y: x + y
```

This is equivalent to:

```python
def sum(x, y):
    return x + y
```

Calling:

```python
print(sum(3, 62))
```

Calculation:

```text
3 + 62 = 65
```

**Output**

```text
65
```

### Lambda vs Normal Function

| Lambda Function | Normal Function |
|-----------------|-----------------|
| `square = lambda x: x * x` | `def square(x): return x * x` |
| Anonymous (no function name required) | Named using `def` |
| Single expression only | Can contain multiple statements |
| No explicit `return` | Uses the `return` statement |
| Best for short operations | Best for complex logic |

### Common Uses of Lambda Functions

Lambda functions are often used with functions like `map()`, `filter()`, and `sorted()`.

Example:

```python
numbers = [1, 2, 3, 4]

squares = list(map(lambda x: x * x, numbers))

print(squares)
```

**Output**

```text
[1, 4, 9, 16]
```

### Summary

- A **lambda function** is a one-line anonymous function.
- It automatically returns the result of its expression.
- It is ideal for simple operations and short-lived functions.
- For larger or more complex logic, use a normal function defined with `def`.
