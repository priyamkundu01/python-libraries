### Code

```python
# Recursion - Fibonacci Series

'''
0 1 1 2 3 5 8 13 ...
0 1 2 3 4 5 6 ...

fib(0) = 0
fib(1) = 1
fib(2) = fib(0) + fib(1)
fib(3) = fib(1) + fib(2)
fib(4) = fib(2) + fib(3)
fib(n) = fib(n-2) + fib(n-1)
'''

def fib(n):
    # Base case of recursion
    if n == 0 or n == 1:
        return n

    # Recursive case
    return fib(n - 2) + fib(n - 1)


print(fib(6))
```

### Output

```text
8
```

### Note

## What is Recursion?

**Recursion** is a programming technique in which a function **calls itself** to solve a problem.

Every recursive function must have:

1. **Base Case** – Stops the recursion.
2. **Recursive Case** – Calls itself with a smaller or simpler problem.

### Function

```python
def fib(n):
    if n == 0 or n == 1:
        return n

    return fib(n - 2) + fib(n - 1)
```

### Base Case

```python
if n == 0 or n == 1:
    return n
```

This prevents infinite recursion.

```text
fib(0) = 0
fib(1) = 1
```

### Recursive Case

```python
return fib(n - 2) + fib(n - 1)
```

This follows the Fibonacci formula:

```text
fib(n) = fib(n-1) + fib(n-2)
```

## Step-by-Step Execution of `fib(6)`

```text
fib(6)
│
├── fib(4)
│   ├── fib(2)
│   │   ├── fib(0) → 0
│   │   └── fib(1) → 1
│   │       fib(2) = 1
│   │
│   └── fib(3)
│       ├── fib(1) → 1
│       └── fib(2)
│           ├── fib(0) → 0
│           └── fib(1) → 1
│           fib(2) = 1
│
│       fib(3) = 2
│
│   fib(4) = 3
│
└── fib(5)
    ├── fib(3)
    │   = 2
    │
    └── fib(4)
        = 3

    fib(5) = 5

fib(6) = 3 + 5 = 8
```

---

## Recursive Call Tree

```text
                           fib(6)
                         /        \
                    fib(4)        fib(5)
                   /     \        /     \
               fib(2)   fib(3) fib(3)  fib(4)
               /   \     /  \    / \    /  \
            f0    f1  f1  f2  f1 f2  f2  f3
```

Notice that:

- `fib(2)` is calculated multiple times.
- `fib(3)` is calculated multiple times.
- `fib(4)` is calculated multiple times.

This repeated computation makes recursive Fibonacci inefficient.

---

## Time Complexity

Recursive Fibonacci has:

```text
Time Complexity: O(2ⁿ)
Space Complexity: O(n)
```

because many subproblems are solved repeatedly.

---

## Better Approach (Dynamic Programming)

```python
def fib(n):
    if n <= 1:
        return n

    a, b = 0, 1

    for _ in range(2, n + 1):
        a, b = b, a + b

    return b

print(fib(6))
```

**Output**

```text
8
```

This iterative solution has:

```text
Time Complexity : O(n)
Space Complexity: O(1)
```

which is much more efficient than the recursive approach.

---

## Summary

- **Recursion** is when a function calls itself.
- Every recursive function needs a **base case** to stop recursion.
- The Fibonacci sequence follows:

  ```text
  fib(n) = fib(n-1) + fib(n-2)
  ```

- `fib(6)` returns **8**.
- Recursive Fibonacci is simple to understand but inefficient due to repeated calculations.
- For large values of `n`, an iterative or dynamic programming solution is preferred.
