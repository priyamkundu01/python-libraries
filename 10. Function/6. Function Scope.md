### Note

## What is Variable Scope?

**Scope** determines where a variable can be accessed in a program.

Python mainly has two types of scope:

1. **Local Scope**
2. **Global Scope**

---

## 1. Local Variables

A **local variable** is created inside a function.

It exists **only while the function is executing**.

Example:

```python
def sum(a, b):
    c = a + b
    z = 1
    return c
```

Here,

- `a`
- `b`
- `c`
- `z`

are **local variables**.

They can only be used inside the `sum()` function.

After the function finishes, these variables are destroyed.

---

## 2. Global Variables

A variable declared outside all functions is called a **global variable**.

Example:

```python
z = 8
```

This variable can be accessed from anywhere in the program (unless it is shadowed by a local variable).

---

## Program Execution

### Step 1

```python
z = 8
```

A global variable `z` is created.

Memory:

```text
Global:
z = 8
```

---

### Step 2

```python
print(z)
```

Python looks for `z`.

It finds the global variable.

Output:

```text
8
```

---

### Step 3

```python
print(sum(4, 6))
```

The function is called.

Inside the function:

```python
a = 4
b = 6

c = 10
z = 1
```

Memory inside the function:

```text
Local:

a = 4
b = 6
c = 10
z = 1
```

Notice that this `z` is **not** the same as the global `z`.

The function returns:

```text
10
```

Output:

```text
10
```

After returning, the local variables are removed from memory.

---

### Step 4

```python
print(z)
```

The local `z` no longer exists.

Python again uses the global variable.

Output:

```text
8
```

---

## Local vs Global Variable

```python
def sum(a, b):
    z = 1      # Local

z = 8          # Global
```

These are **different variables** even though they have the same name.

The local variable temporarily hides (or **shadows**) the global variable **inside the function**.

---


---

## Access Rules

| Variable | Accessible Inside Function | Accessible Outside Function |
|----------|----------------------------|-----------------------------|
| Local Variable | ✔ Yes | ✘ No |
| Global Variable | ✔ Yes (read-only by default) | ✔ Yes |

---

## Example

```python
x = 100

def demo():
    y = 50
    print(x)   # Global variable
    print(y)   # Local variable

demo()

print(x)
# print(y)   # Error
```

Output:

```text
100
50
100
```

Attempting to access `y` outside the function results in:

```text
NameError: name 'y' is not defined
```

---

## Summary

- **Local variables** are created inside a function and exist only during that function call.
- **Global variables** are created outside functions and can be accessed throughout the program.
- A local variable with the same name as a global variable **shadows** the global variable inside the function.
- When `sum()` finishes, all of its local variables are destroyed.
- Therefore, the global variable `z` remains unchanged.
