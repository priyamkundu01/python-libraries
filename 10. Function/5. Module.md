### Note

## What is a Module?

A **module** is a Python file (`.py`) that contains functions, classes, or variables that can be reused in other Python programs.

For example:

```text
mymodule.py
```

contains

```python
def hello():
    print("Hello world")
```

This function can be used in another file by importing the module.

---

## Types of Modules

Python has **two main types** of modules.

### 1. Built-in Modules

These modules come pre-installed with Python.

Examples:

- `math`
- `os`
- `random`
- `datetime`
- `sys`

Example:

```python
import math

print(math.sqrt(16))
```

**Output**

```text
4.0
```

---

### 2. External Modules

These modules are created by other developers and must usually be installed using **pip**.

Example:

```bash
pip install requests
```

Then import it:

```python
import requests
```

---

## Using the `math` Module

```python
import math

print(math.sqrt(16))
```

The `sqrt()` function calculates the square root.

Output:

```text
4.0
```

---

## Using the `os` Module

```python
import os
```

The `os` module provides functions to interact with the operating system.

Examples:

```python
print(os.getcwd())      # Current working directory

print(os.listdir())     # List files and folders

os.mkdir("NewFolder")   # Create a folder
```

---

## Using the `requests` Module

The `requests` module is used to make HTTP requests.

```python
import requests

r = requests.get("https://www.google.com")

print(r.text)
```

Explanation:

- `requests.get()` sends an HTTP **GET** request.
- `r` is a **Response object**.
- `r.text` contains the webpage's HTML source code.

Output begins with something like:

```html
<!doctype html>
<html>
...
```

---

## Import Syntax

Import an entire module:

```python
import math
```

Import a specific function:

```python
from math import sqrt

print(sqrt(16))
```

Import with an alias:

```python
import math as m

print(m.sqrt(25))
```

### Key Points

- A **module** is a reusable Python file.
- Python modules can be:
  - **Built-in**
  - **External**
  - **User-defined**
- Use `import module_name` to access a module.
- The `requests` module must usually be installed using:

```bash
pip install requests
```

- Custom modules should be in the same directory (or Python path) to be imported successfully.
