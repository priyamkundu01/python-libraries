### Code

```python
# Set Union and Intersection

a = {3, 23, 1}
b = {23, 4, 2, 55, 1}

# Contains all the elements in a and b
c = a.union(b)
print(c)

# Contains only the common elements
d = a.intersection(b)
print(d)
```

### Output

```text
{1, 2, 3, 4, 23, 55}
{1, 23}
```

> **Note:** Since sets are **unordered**, your output may appear in a different order, such as:

```text
{3, 23, 1, 4, 2, 55}
{23, 1}
```

Both outputs are correct.

### Note

## Set Operations

Python provides several built-in operations for working with sets.

The two most commonly used operations are:

1. **Union (`union()`)**
2. **Intersection (`intersection()`)**

---

## Initial Sets

```python
a = {3, 23, 1}
```

```text
a = {3, 23, 1}
```

```python
b = {23, 4, 2, 55, 1}
```

```text
b = {23, 4, 2, 55, 1}
```

---

## `union()` Method

```python
c = a.union(b)
```

The `union()` method returns a **new set** containing **all unique elements** from both sets.

Duplicate elements appear only once.

### Visualization

```text
a = {3, 23, 1}
b = {23, 4, 2, 55, 1}

Union
↓
{1, 2, 3, 4, 23, 55}
```

Output:

```text
{1, 2, 3, 4, 23, 55}
```

---

## `intersection()` Method

```python
d = a.intersection(b)
```

The `intersection()` method returns a **new set** containing only the elements that are present in **both** sets.

### Visualization

```text
a = {3, 23, 1}
b = {23, 4, 2, 55, 1}

Common elements

23
1
```

Result:

```text
{1, 23}
```

Output:

```text
{1, 23}
```

---

## Difference Between Union and Intersection

| Union | Intersection |
|-------|--------------|
| Returns all unique elements | Returns only common elements |
| Combines both sets | Finds shared elements |
| `a.union(b)` | `a.intersection(b)` |

---

## Other Common Set Operations

### Difference

Returns elements that are in the first set but **not** in the second.

```python
a = {1, 2, 3}
b = {2, 3, 4}

print(a.difference(b))
```

Output:

```text
{1}
```

---

### Symmetric Difference

Returns elements that are in either set, but **not in both**.

```python
a = {1, 2, 3}
b = {2, 3, 4}

print(a.symmetric_difference(b))
```

Output:

```text
{1, 4}
```

---

### Subset

Checks whether one set is contained within another.

```python
a = {1, 2}
b = {1, 2, 3}

print(a.issubset(b))
```

Output:

```text
True
```

---

### Superset

Checks whether one set contains all elements of another.

```python
b = {1, 2, 3}
a = {1, 2}

print(b.issuperset(a))
```

Output:

```text
True
```

---

## Summary

| Method | Description | Example |
|---------|-------------|---------|
| `union()` | Returns all unique elements from both sets | `a.union(b)` |
| `intersection()` | Returns common elements | `a.intersection(b)` |
| `difference()` | Elements in first set but not second | `a.difference(b)` |
| `symmetric_difference()` | Elements in either set but not both | `a.symmetric_difference(b)` |

### Key Points

- Sets automatically remove duplicate values.
- `union()` combines all unique elements.
- `intersection()` finds common elements.
- These methods return **new sets** and do not modify the original sets.
- The order of elements in a set is **not guaranteed**.
