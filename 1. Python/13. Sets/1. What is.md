### Output


Both outputs are correct.

### Note

## What is a Set?

A **set** is an unordered collection of **unique** elements in Python.

Sets are used when:

- Duplicate values should not be stored.
- Fast membership testing is needed.
- The order of elements does not matter.

Sets are created using curly braces `{}`.

### Syntax

```python
set_name = {item1, item2, item3}
```

Example:

```python
s = {3, 23, 2, 11}
```

---

## Printing a Set

```python
print(s)
```

Possible output:

```text
{3, 23, 2, 11}
```

or

```text
{11, 2, 3, 23}
```

The order may change because **sets are unordered**.

---

## Checking the Type

```python
print(type(s))
```

Output:

```text
<class 'set'>
```

---

## Sets Do Not Support Indexing

Unlike lists and tuples, sets **do not have indexes**.

This is **not allowed**:

```python
print(s[3])
```

Output:

```text
TypeError: 'set' object is not subscriptable
```

Since a set has no fixed order, Python cannot determine what the "4th element" is.

---

## Properties of Sets

- Unordered
- Mutable (elements can be added or removed)
- Do not allow duplicate values
- Cannot be indexed or sliced
- Elements must be hashable (immutable types like integers, strings, tuples)

---

## Duplicate Values

If duplicate values are added, Python automatically removes them.

Example:

```python
numbers = {1, 2, 2, 3, 3, 3}

print(numbers)
```

Output:

```text
{1, 2, 3}
```

---

## Creating an Empty Set

To create an empty set, use:

```python
s = set()
```

Output:

```python
print(type(s))
```

```text
<class 'set'>
```

⚠️ Do **not** use:

```python
s = {}
```

because this creates an **empty dictionary**, not a set.

Example:

```python
print(type({}))
```

Output:

```text
<class 'dict'>
```

---

## Common Set Operations

Add an element:

```python
s.add(50)
```

Remove an element:

```python
s.remove(23)
```

Discard an element:

```python
s.discard(100)
```

Check membership:

```python
print(23 in s)
```

Output:

```text
True
```

---

## Set vs List vs Tuple

| Feature | List | Tuple | Set |
|---------|------|-------|-----|
| Syntax | `[]` | `()` | `{}` |
| Ordered | ✔ Yes | ✔ Yes | ✘ No |
| Mutable | ✔ Yes | ✘ No | ✔ Yes |
| Duplicate Values | ✔ Allowed | ✔ Allowed | ✘ Not Allowed |
| Indexing | ✔ Yes | ✔ Yes | ✘ No |

---

## Summary

- A **set** is an unordered collection of **unique** elements.
- Sets are created using `{}`.
- Duplicate values are automatically removed.
- Sets do **not** support indexing or slicing.
- The order of elements is not guaranteed.
- Create an empty set using:

  ```python
  set()
  ```

  not `{}`, because `{}` creates a dictionary.
