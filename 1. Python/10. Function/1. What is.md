### Note

A **function** is a reusable block of code that performs a specific task. Instead of writing the same code multiple times, you can define a function once and call it whenever needed.

### Function Syntax

```python
def function_name(parameters):
    # Function body
    return value
```

### Explanation of the Program

```python
def average(a, b, c):
    d = (a + b + c) / 3.0
    return d
```

- `def` is the keyword used to define a function.
- `average` is the function name.
- `a`, `b`, and `c` are **parameters** (inputs to the function).
- The average of the three numbers is calculated and stored in `d`.
- `return d` sends the result back to the caller.

### Function Calls

```python
o1 = average(3, 5, 1)
```

Calculation:

```text
(3 + 5 + 1) / 3
= 9 / 3
= 3.0
```

So,

```python
o1 = 3.0
```

---

```python
o2 = average(4, 2, 1)
```

Calculation:

```text
(4 + 2 + 1) / 3
= 7 / 3
= 2.3333333333333335
```

So,

```python
o2 = 2.3333333333333335
```

### Output

### Parameters vs Arguments

| Parameter | Argument |
|-----------|----------|
| Variables defined in the function definition | Actual values passed to the function |
| `a`, `b`, `c` | `3`, `5`, `1` |

Example:

```python
def average(a, b, c):   # Parameters
    ...

average(3, 5, 1)         # Arguments
```

### Why Use Functions?

- Avoid repeating code (**code reusability**).
- Make programs easier to read.
- Make debugging and maintenance easier.
- Break large programs into smaller, manageable parts.

### Summary

- Use `def` to create a function.
- Pass values using **arguments**.
- Receive values using **parameters**.
- Use `return` to send the result back to the caller.
- A function can be called as many times as needed with different inputs.
