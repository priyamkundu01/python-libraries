### Code

```python
# Function Docstrings

def sum(a, b):
    '''This will sum two numbers'''
    c = a + b
    return c


print(sum.__doc__)
```

### Output

```text
This will sum two numbers
```

### Note

## What is a Docstring?

A **docstring** (documentation string) is a special string used to describe what a function, class, module, or method does.

It is written immediately below the function definition using triple quotes (`''' '''` or `""" """`).

Python stores the docstring in the function's `__doc__` attribute.

---

## Syntax

```python
def function_name(parameters):
    """Docstring"""
    # Function body
```

or

```python
def function_name(parameters):
    '''Docstring'''
    # Function body
```

---

## Program Explanation

### Function Definition

```python
def sum(a, b):
    '''This will sum two numbers'''
    c = a + b
    return c
```

Here:

- `sum` is the function name.
- `a` and `b` are parameters.
- `'''This will sum two numbers'''` is the **docstring**.
- `return c` returns the sum of the two numbers.

---

### Accessing the Docstring

```python
print(sum.__doc__)
```

Every function has a special attribute called `__doc__`.

It returns the function's documentation string.

Output:

```text
This will sum two numbers
```

---

## Why Use Docstrings?

Docstrings help:

- Explain what a function does.
- Improve code readability.
- Generate automatic documentation.
- Help other programmers understand your code.
- Display documentation in Python's built-in `help()` function.

---

## Example

```python
def multiply(a, b):
    """Returns the product of two numbers."""
    return a * b

print(multiply.__doc__)
```

Output:

```text
Returns the product of two numbers.
```

---

## Using `help()`

Instead of `__doc__`, you can also use:

```python
help(sum)
```

Output (simplified):

```text
Help on function sum:

sum(a, b)
    This will sum two numbers
```

---

## Difference Between Comments and Docstrings

| Comments | Docstrings |
|----------|------------|
| Written using `#` | Written using triple quotes (`''' '''` or `""" """`) |
| Explain code for programmers | Describe functions, classes, or modules |
| Ignored by Python | Stored in the `__doc__` attribute |
| Cannot be accessed at runtime | Can be accessed using `__doc__` or `help()` |

---

## Best Practices

- Write a docstring immediately after the function definition.
- Clearly describe what the function does.
- For larger functions, include:
  - Purpose
  - Parameters
  - Return value
  - Exceptions (if any)

Example:

```python
def divide(a, b):
    """
    Returns the quotient of two numbers.

    Parameters:
        a (int): Dividend
        b (int): Divisor

    Returns:
        float: Result of division
    """
    return a / b
```

---

## Summary

- A **docstring** is a string that documents a function, class, or module.
- It is written immediately below the function definition using triple quotes.
- Python stores it in the `__doc__` attribute.
- You can view it using:
  - `function_name.__doc__`
  - `help(function_name)`
- Docstrings make code easier to understand and maintain.
