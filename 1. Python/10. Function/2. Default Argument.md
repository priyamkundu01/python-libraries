### Code

```python
# Default Arguments

def add(a, b, plus=0):
    x = a + b + plus
    return x


c = add(3, 5, 2)
print(c)

c1 = add(b=5, a=3)
print(c1)
```

### Output

```text
10
8
```

### Note

A **default argument** is a parameter that has a predefined value. If no value is provided when the function is called, Python automatically uses the default value.

### Function Definition

```python
def add(a, b, plus=0):
    x = a + b + plus
    return x
```

- `a` and `b` are **required parameters**.
- `plus=0` is a **default parameter**.
- If `plus` is not provided, its value will be `0`.

### Example 1: Passing All Arguments

```python
c = add(3, 5, 2)
print(c)
```

Calculation:

```text
3 + 5 + 2 = 10
```

**Output**

```text
10
```

### Example 2: Using the Default Argument

```python
c1 = add(b=5, a=3)
print(c1)
```

Here:

- `a = 3`
- `b = 5`
- `plus` is **not provided**, so Python uses the default value:

```python
plus = 0
```

Calculation:

```text
3 + 5 + 0 = 8
```

**Output**

```text
8
```

### Keyword Arguments

This function call:

```python
add(b=5, a=3)
```

uses **keyword arguments**, where arguments are passed by parameter name instead of position.

These two function calls are equivalent:

```python
add(3, 5)
```

```python
add(a=3, b=5)
```

### Rules for Default Arguments

- Parameters with default values should come **after** required parameters.

✔ Correct:

```python
def add(a, b, plus=0):
    ...
```

❌ Incorrect:

```python
def add(plus=0, a, b):
    ...
```

This will produce a **SyntaxError**.

### Summary

- A **default argument** provides a value if none is supplied.
- **Keyword arguments** let you specify parameters by name.
- Default arguments make functions more flexible and easier to use.
- If a value is passed for the default parameter, it overrides the default value.
