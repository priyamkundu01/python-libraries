```python
def sum(a, b):
    print("Hey I am summing")

    c = a + b

    z = 0      # Updates the global variable instead of creating a local one

    return c


z = 3

print(sum(3, 12))
print(z)
```

```text

```

### Note

## What is the `global` Keyword?

The **`global`** keyword is used to tell Python that a variable inside a function refers to the **global variable**, not a new local variable.

Without `global`, assigning a value to a variable inside a function creates a **local variable**.

With `global`, the function modifies the variable defined outside the function.

## Without `global`

```python
z = 3

def demo():
    z = 10

demo()

print(z)
```

Output:

```text
3
```

Explanation:

- `z = 10` creates a **local variable**.
- The global variable remains unchanged.

---

## With `global`

```python
z = 3

def demo():
    global z
    z = 10

demo()

print(z)
```

Output:

```text
10
```

Explanation:

- `global z` refers to the variable outside the function.
- Assigning `z = 10` updates the global variable.

---

## Local vs Global Variables

| Local Variable | Global Variable |
|---------------|-----------------|
| Created inside a function | Created outside all functions |
| Exists only during the function call | Exists throughout the program |
| Cannot be accessed outside the function | Can be accessed anywhere (read-only by default inside functions) |
| Disappears after the function returns | Remains in memory until the program ends |

---

## When Should You Use `global`?

Use `global` only when you intentionally want to modify a global variable.

In most cases, it is better to:

- Pass values as function arguments.
- Return values from functions.

This makes programs easier to understand, test, and maintain.
