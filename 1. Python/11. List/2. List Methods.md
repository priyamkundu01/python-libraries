### Code

```python
# List Methods

marks = [5, 2, 21, 5, 7]
extra_marks = [53, 23, 32]

print(marks)

# marks.append(63)   # Adds an element to the end of the list
# marks.pop()        # Removes the last element

marks.extend(extra_marks)

print(marks)
```

### Output

```text
[5, 2, 21, 5, 7]
[5, 2, 21, 5, 7, 53, 23, 32]
```

### Note

## What are List Methods?

**List methods** are built-in functions that perform operations on Python lists, such as adding, removing, sorting, or modifying elements.

Since lists are **mutable**, these methods modify the original list.

---

## Program Explanation

### Initial List

```python
marks = [5, 2, 21, 5, 7]
```

Another list:

```python
extra_marks = [53, 23, 32]
```

Initially,

```text
marks = [5, 2, 21, 5, 7]
```

Output:

```text
[5, 2, 21, 5, 7]
```

---

## `extend()` Method

```python
marks.extend(extra_marks)
```

The `extend()` method adds **all elements** from another iterable (such as a list) to the end of the existing list.

Before:

```text
marks = [5, 2, 21, 5, 7]
```

```text
extra_marks = [53, 23, 32]
```

After:

```text
marks = [5, 2, 21, 5, 7, 53, 23, 32]
```

Output:

```text
[5, 2, 21, 5, 7, 53, 23, 32]
```

---

## `append()` Method

```python
marks.append(63)
```

Adds a **single element** to the end of the list.

Example:

```python
marks = [5, 2, 21]

marks.append(63)

print(marks)
```

Output:

```text
[5, 2, 21, 63]
```

---

## `pop()` Method

```python
marks.pop()
```

Removes and returns the **last element** of the list.

Example:

```python
marks = [5, 2, 21, 63]

marks.pop()

print(marks)
```

Output:

```text
[5, 2, 21]
```

You can also remove an element at a specific index:

```python
marks.pop(1)
```

Example:

```text
Before: [5, 2, 21]
After : [5, 21]
```

---

## Difference Between `append()` and `extend()`

| `append()` | `extend()` |
|------------|------------|
| Adds one element | Adds all elements of another iterable |
| List length increases by 1 | List length increases by the number of added elements |
| Can add any object | Expects an iterable (list, tuple, string, etc.) |

Example:

```python
a = [1, 2]
b = [3, 4]

a.append(b)
print(a)
```

Output:

```text
[1, 2, [3, 4]]
```

Using `extend()`:

```python
a = [1, 2]
b = [3, 4]

a.extend(b)
print(a)
```

Output:

```text
[1, 2, 3, 4]
```

## Other Common List Methods

| Method | Description |
|---------|-------------|
| `append(x)` | Adds one element at the end |
| `extend(iterable)` | Adds all elements from another iterable |
| `insert(i, x)` | Inserts an element at index `i` |
| `remove(x)` | Removes the first occurrence of `x` |
| `pop()` | Removes and returns the last element |
| `pop(i)` | Removes and returns the element at index `i` |
| `clear()` | Removes all elements |
| `sort()` | Sorts the list in ascending order |
| `reverse()` | Reverses the order of elements |
| `count(x)` | Counts occurrences of `x` |
| `index(x)` | Returns the index of the first occurrence of `x` |
| `copy()` | Creates a shallow copy of the list |

---

## Summary

- Lists are **mutable**, so list methods modify the original list.
- `append()` adds **one element** to the end.
- `extend()` adds **all elements** from another iterable.
- `pop()` removes and returns an element (last element by default).
- Python provides many built-in methods to efficiently manipulate lists.
