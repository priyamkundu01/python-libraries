### Code

```python
# Lists

marks = [54, 23, 64, 93, 32]
mixed = [43, "Hello", False, 4.2]

print(marks[2:4])
print(marks[2])
print(mixed[4])   # Error: Index out of range
```

### Output

```text
[64, 93]
64
IndexError: list index out of range
```

### Note

## What is a List?

A **list** is a collection of items stored in a single variable.

Lists in Python are:

- Ordered
- Mutable (can be changed)
- Allow duplicate values
- Can store different data types

Lists are created using square brackets `[]`.

### Syntax

```python
list_name = [item1, item2, item3, ...]
```

Example:

```python
marks = [54, 23, 64, 93, 32]
```

---

## List with Different Data Types

```python
mixed = [43, "Hello", False, 4.2]
```

A Python list can contain different types of data.

| Element | Data Type |
|---------|-----------|
| `43` | Integer (`int`) |
| `"Hello"` | String (`str`) |
| `False` | Boolean (`bool`) |
| `4.2` | Float (`float`) |

---

## List Indexing

Python uses **zero-based indexing**.

For the `marks` list:

```text
marks = [54, 23, 64, 93, 32]

Index:   0   1   2   3   4
Value:  54  23  64  93  32
```

---

## Accessing an Element

```python
print(marks[2])
```

Index `2` contains:

```text
64
```

Output:

```text
64
```

---

## List Slicing

```python
print(marks[2:4])
```

Syntax:

```python
list[start:stop]
```

- `start` is included.
- `stop` is excluded.

For:

```text
marks = [54, 23, 64, 93, 32]
```

```text
Index:   0   1   2   3   4
Value:  54  23  64  93  32
```

```python
marks[2:4]
```

returns:

```text
[64, 93]
```

Output:

```text
[64, 93]
```

---

## Index Out of Range

```python
print(mixed[4])
```

The `mixed` list has only **4 elements**.

```text
mixed = [43, "Hello", False, 4.2]

Index:   0      1        2      3
```

There is **no element at index `4`**.

Python raises:

```text
IndexError: list index out of range
```

---

## Negative Indexing

Lists also support negative indexing.

```text
marks = [54, 23, 64, 93, 32]

Index:    0   1   2   3   4
Negative: -5 -4 -3 -2 -1
```

Example:

```python
print(marks[-1])
```

Output:

```text
32
```

---

## Common List Operations

```python
numbers = [10, 20, 30]

print(len(numbers))
```

Output:

```text
3
```

Add an element:

```python
numbers.append(40)
```

Remove an element:

```python
numbers.remove(20)
```

Modify an element:

```python
numbers[1] = 25
```

---

## Summary

- A **list** stores multiple values in a single variable.
- Lists are **ordered**, **mutable**, and can contain **different data types**.
- Indexing starts from **0**.
- Slicing uses:

  ```python
  list[start:stop]
  ```

- Accessing an invalid index results in:

  ```text
  IndexError: list index out of range
  ```
