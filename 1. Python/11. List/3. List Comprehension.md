### Code

```python
# Create a list containing the table of 5

# Using a for loop

# table = []

# for i in range(1, 11):
#     table.append(5 * i)

# Using List Comprehension

table = [5 * i for i in range(1, 11)]

print(table)
```

### Output

```text
[5, 10, 15, 20, 25, 30, 35, 40, 45, 50]
```

### Note

## What is List Comprehension?

**List comprehension** is a concise and Pythonic way to create lists.

Instead of writing multiple lines using a `for` loop and `append()`, you can create a list in a single line.

### Syntax

```python
new_list = [expression for item in iterable]
```

- **expression** → Value to be added to the list.
- **item** → Variable representing each element.
- **iterable** → Sequence to iterate over (list, tuple, range, etc.).

---

## Using a `for` Loop

```python
table = []

for i in range(1, 11):
    table.append(5 * i)
```

### Step-by-Step

Initially:

```text
table = []
```

Iterations:

| i | 5 × i | List after `append()` |
|---|-------|------------------------|
| 1 | 5 | `[5]` |
| 2 | 10 | `[5, 10]` |
| 3 | 15 | `[5, 10, 15]` |
| 4 | 20 | `[5, 10, 15, 20]` |
| 5 | 25 | `[5, 10, 15, 20, 25]` |
| 6 | 30 | `[5, 10, 15, 20, 25, 30]` |
| 7 | 35 | `[5, 10, 15, 20, 25, 30, 35]` |
| 8 | 40 | `[5, 10, 15, 20, 25, 30, 35, 40]` |
| 9 | 45 | `[5, 10, 15, 20, 25, 30, 35, 40, 45]` |
| 10 | 50 | `[5, 10, 15, 20, 25, 30, 35, 40, 45, 50]` |

---

## Using List Comprehension

```python
table = [5 * i for i in range(1, 11)]
```

This performs the same task as the `for` loop in a single line.

Breaking it down:

```python
5 * i
```

Calculates the value to store.

```python
for i in range(1, 11)
```

Loops from `1` to `10`.

Python automatically creates the list.

Result:

```text
[5, 10, 15, 20, 25, 30, 35, 40, 45, 50]
```

---

## Comparison

### Traditional Method

```python
table = []

for i in range(1, 11):
    table.append(5 * i)
```

### List Comprehension

```python
table = [5 * i for i in range(1, 11)]
```

Both produce the same output.

---

## List Comprehension with Condition

You can also include an `if` condition.

Example:

```python
numbers = [i for i in range(1, 11) if i % 2 == 0]

print(numbers)
```

Output:

```text
[2, 4, 6, 8, 10]
```

This creates a list containing only even numbers.

---

## Advantages of List Comprehension

- Shorter and cleaner code.
- Easy to read.
- Faster than using a loop with `append()` in many cases.
- Preferred Pythonic way to create lists.

---

## Summary

- **List comprehension** creates a new list in a single line.
- General syntax:

  ```python
  [expression for item in iterable]
  ```

- It replaces the combination of a `for` loop and `append()`.
- It can also include conditions using `if`.
- In this example, it generates the multiplication table of **5**.
