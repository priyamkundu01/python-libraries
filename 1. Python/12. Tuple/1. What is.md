### Code

```python
# Tuple

a = (3, 2, 22, 13)

print(a)
print(a[2])

a[3] = 32   # Error: Tuples are immutable

b = (3,)    # Tuple with one element
```

### Output

```text
(3, 2, 22, 13)
22
TypeError: 'tuple' object does not support item assignment
```

### Note

## What is a Tuple?

A **tuple** is an ordered collection of items in Python.

Like lists, tuples can store multiple values, but unlike lists, **tuples are immutable**, meaning their elements **cannot be changed** after creation.

Tuples are created using parentheses `()`.

### Syntax

```python
tuple_name = (item1, item2, item3)
```

Example:

```python
a = (3, 2, 22, 13)
```

---

## Tuple Indexing

Python uses **zero-based indexing**.

```text
a = (3, 2, 22, 13)

Index:   0   1   2   3
Value:   3   2  22  13
```

Accessing an element:

```python
print(a[2])
```

Output:

```text
22
```

---

## Printing a Tuple

```python
print(a)
```

Output:

```text
(3, 2, 22, 13)
```

---

## Tuple Immutability

The following statement:

```python
a[3] = 32
```

tries to change the fourth element.

Since tuples are **immutable**, Python raises an error.

Output:

```text
TypeError: 'tuple' object does not support item assignment
```

This means tuple elements cannot be:

- Modified
- Added
- Removed

after the tuple is created.

---

## Single-Element Tuple

```python
b = (3,)
```

This is a tuple containing one element.

Notice the comma `,`.

Without the comma:

```python
b = (3)
```

Python treats it as an integer, not a tuple.

Check the types:

```python
print(type((3)))
```

Output:

```text
<class 'int'>
```

```python
print(type((3,)))
```

Output:

```text
<class 'tuple'>
```

---

## Tuple vs List

| List | Tuple |
|------|-------|
| Uses `[]` | Uses `()` |
| Mutable | Immutable |
| Can add/remove/modify elements | Cannot modify elements |
| Slightly slower | Slightly faster |
| More memory usage | Less memory usage |

Example:

List:

```python
numbers = [1, 2, 3]
numbers[0] = 10

print(numbers)
```

Output:

```text
[10, 2, 3]
```

Tuple:

```python
numbers = (1, 2, 3)
numbers[0] = 10
```

Output:

```text
TypeError: 'tuple' object does not support item assignment
```

---

## Common Tuple Operations

Length:

```python
a = (3, 2, 22, 13)

print(len(a))
```

Output:

```text
4
```

Count occurrences:

```python
print(a.count(2))
```

Output:

```text
1
```

Find index:

```python
print(a.index(22))
```

Output:

```text
2
```

---

## Summary

- A **tuple** is an ordered collection of elements.
- Tuples are **immutable**, so their values cannot be changed.
- Indexing starts from **0**.
- A single-element tuple must include a comma:

  ```python
  (3,)
  ```

- Attempting to modify a tuple results in:

  ```text
  TypeError: 'tuple' object does not support item assignment
  ```
