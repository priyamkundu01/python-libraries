### Code

```python
# Tuple Unpacking

tu = (3, 2, 45)

print(a, b, c)
```

### Output

```text

```

### Note

## What is Tuple Unpacking?

**Tuple unpacking** is the process of assigning the elements of a tuple to multiple variables in a single statement.

Instead of accessing each element using its index, Python automatically assigns each element to a corresponding variable.

### Syntax

```python
variable1, variable2, ... = tuple
```

Example:

```python
a, b, c = (3, 2, 45)
```

---

## Program Explanation

### Step 1: Create a Tuple

```python
tu = (3, 2, 45)
```

The tuple contains three elements.

```text
Index:   0   1   2
Value:   3   2  45
```

---

### Step 2: Unpack the Tuple

```python
a, b, c = tu
```

Python automatically assigns:

```text
a = 3
b = 2
c = 45
```

This is equivalent to writing:

```python
a = tu[0]
b = tu[1]
c = tu[2]
```

but tuple unpacking is shorter and more readable.

---

### Step 3: Print the Variables

```python
print(a, b, c)
```

Output:

```text
3 2 45
```

---

---

## Rules of Tuple Unpacking

The number of variables must match the number of elements in the tuple.

✔ Correct:

```python
t = (10, 20, 30)

a, b, c = t
```

Output:

```text
10 20 30
```

---

❌ Incorrect (Too Few Variables)

```python
t = (10, 20, 30)

a, b = t
```

Output:

```text
ValueError: too many values to unpack (expected 2)
```

---

❌ Incorrect (Too Many Variables)

```python
t = (10, 20)

a, b, c = t
```

Output:

```text
ValueError: not enough values to unpack (expected 3, got 2)
```

---

## Extended Unpacking

Python allows one variable to collect multiple remaining values using `*`.

Example:

```python
t = (1, 2, 3, 4, 5)

a, *b = t

print(a)
print(b)
```

Output:

```text
1
[2, 3, 4, 5]
```

Another example:

```python
t = (1, 2, 3, 4, 5)

a, *b, c = t

print(a)
print(b)
print(c)
```

Output:

```text
1
[2, 3, 4]
5
```

---

## Advantages of Tuple Unpacking

- Short and readable code.
- No need to access elements using indexes.
- Useful for returning multiple values from functions.
- Commonly used in loops and assignments.

Example:

```python
point = (10, 20)

x, y = point

print(x)
print(y)
```

Output:

```text
10
20
```

---

## Summary

- **Tuple unpacking** assigns tuple elements to variables in one statement.
- The number of variables should normally match the number of tuple elements.
- Use `*` for extended unpacking when needed.
- Tuple unpacking makes code cleaner, shorter, and easier to read.
