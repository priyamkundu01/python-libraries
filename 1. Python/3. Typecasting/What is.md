
### Convert Integer variable to String

``` python
a = 34
print(type(a)) #int

c = string(a)
print(type(c)) #string
```

### Convert String variable to Integer

``` python
a = "Priyam"
print(type(a)) #string

c = string(a)
print(type(c)) #int
```

### Convert Float to Integer

``` python
pi = 3.14

pi_int = int(pi)

print(pi_int) # Output: 3
print(type(pi_int)) # int
```

### Convert Integer to Float

``` python
pi = 3

pi_float = float(pi)

print(pi_float) # Output: 3.0
print(type(pi_float)) # float
```
