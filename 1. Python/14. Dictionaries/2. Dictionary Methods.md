### Note

## What are Dictionary Methods?

**Dictionary methods** are built-in functions that allow you to manipulate and retrieve data from a dictionary.

Some commonly used dictionary methods are:

- `keys()`
- `values()`
- `items()`
- `get()`
- `pop()`
- `clear()`
- `update()`
- `copy()`

---

## Initial Dictionary

```python
marks = {
    "harry": 34,
    "jack": 45,
    "lily": 94
}
```

Representation:

```text
"harry" ──► 34
"jack"  ──► 45
"lily"  ──► 94
```

---

## `keys()` Method

```python
print(marks.keys())
```

The `keys()` method returns a **view object** containing all the keys of the dictionary.

Output:

```text
dict_keys(['harry', 'jack', 'lily'])
```

If needed, you can convert it to a list:

```python
print(list(marks.keys()))
```

Output:

```text
['harry', 'jack', 'lily']
```

---

## `values()` Method

```python
print(marks.values())
```

The `values()` method returns a **view object** containing all the values.

Output:

```text
dict_values([34, 45, 94])
```

Convert it to a list if required:

```python
print(list(marks.values()))
```

Output:

```text
[34, 45, 94]
```

---

## `pop()` Method

```python
marks.pop("lily")
```

The `pop()` method removes the specified key and returns its value.

Before:

```text
{
    "harry": 34,
    "jack": 45,
    "lily": 94
}
```

After removing `"lily"`:

```text
{
    "harry": 34,
    "jack": 45
}
```

Output:

```text
{'harry': 34, 'jack': 45}
```

### If the Key Does Not Exist

```python
marks.pop("tom")
```

Output:

```text
KeyError: 'tom'
```

To avoid an error, provide a default value:

```python
marks.pop("tom", None)
```

Output:

```text
None
```

---

## `clear()` Method

```python
marks.clear()
```

Removes **all key-value pairs** from the dictionary.

Example:

```python
marks = {
    "harry": 34,
    "jack": 45
}

marks.clear()

print(marks)
```

Output:

```text
{}
```

---

## Other Common Dictionary Methods

### `get()`

Returns the value of a key without raising an error if the key is missing.

```python
print(marks.get("harry"))
print(marks.get("tom"))
```

Output:

```text
34
None
```

---

### `items()`

Returns both keys and values as tuples.

```python
print(marks.items())
```

Output:

```text
dict_items([('harry', 34), ('jack', 45), ('lily', 94)])
```

---

### `update()`

Adds new key-value pairs or updates existing ones.

```python
marks.update({"tom": 88})

print(marks)
```

Output:

```text
{'harry': 34, 'jack': 45, 'lily': 94, 'tom': 88}
```

---

### `copy()`

Creates a shallow copy of the dictionary.

```python
new_marks = marks.copy()
```

---

## Common Dictionary Methods Summary

| Method | Description | Example |
|---------|-------------|---------|
| `keys()` | Returns all keys | `marks.keys()` |
| `values()` | Returns all values | `marks.values()` |
| `items()` | Returns key-value pairs | `marks.items()` |
| `get(key)` | Returns the value for a key | `marks.get("harry")` |
| `pop(key)` | Removes and returns the value of a key | `marks.pop("lily")` |
| `update(dict)` | Adds or updates key-value pairs | `marks.update({...})` |
| `copy()` | Creates a shallow copy | `marks.copy()` |
| `clear()` | Removes all entries | `marks.clear()` |
