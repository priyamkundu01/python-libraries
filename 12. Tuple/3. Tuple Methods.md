### Note

## What are Tuple Methods?

Since **tuples are immutable**, they have only a few built-in methods.

The two most commonly used tuple methods are:

1. `count()`
2. `index()`

---

## Tuple

```python
t = (3, 12, 1, 54, 23, 12)
```

The tuple contains six elements.

```text
Index:   0   1   2   3   4   5
Value:   3  12   1  54  23  12
```

---

## `count()` Method

```python
print(t.count(12))
```

The `count()` method returns the number of times a specified value appears in the tuple.

Syntax:

```python
tuple.count(value)
```

For the tuple:

```text
(3, 12, 1, 54, 23, 12)
```

The value `12` appears:

- At index `1`
- At index `5`

Total occurrences:

```text
2
```

Output:

```text
2
```

---

## `index()` Method

```python
print(t.index(12))
```

The `index()` method returns the **index of the first occurrence** of a specified value.

Syntax:

```python
tuple.index(value)
```

The first occurrence of `12` is at index:

```text
1
```

Output:

```text
1
```

Even though `12` also appears at index `5`, `index()` always returns the **first** matching index.

---

## Example

```python
numbers = (10, 20, 30, 20)

print(numbers.count(20))
print(numbers.index(20))
```

Output:

```text
2
1
```

---

## If the Element is Not Present

Using `count()`:

```python
t = (1, 2, 3)

print(t.count(5))
```

Output:

```text
0
```

Using `index()`:

```python
t = (1, 2, 3)

print(t.index(5))
```

Output:

```text
ValueError: tuple.index(x): x not in tuple
```

---

## Other Useful Built-in Functions with Tuples

Although they are not tuple methods, Python provides many built-in functions that work with tuples.

Example:

```python
t = (3, 12, 1, 54, 23, 12)

print(len(t))
print(max(t))
print(min(t))
print(sum(t))
```

Output:

```text
6
54
1
105
```

---

## Summary

| Method | Description | Example |
|---------|-------------|---------|
| `count(x)` | Counts how many times `x` appears | `t.count(12)` → `2` |
| `index(x)` | Returns the index of the first occurrence of `x` | `t.index(12)` → `1` |

### Key Points

- Tuples are **immutable**, so they have very few methods.
- `count()` returns the number of occurrences of a value.
- `index()` returns the **first** index where the value is found.
- If the value is not present:
  - `count()` returns `0`.
  - `index()` raises a `ValueError`.

### Final Output
