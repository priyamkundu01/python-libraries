### Code

```python
# Set Methods

s = {34, 23, 1, 3, 22}

print(s)

s.add(32)
s.add(322)

s.remove(1)

# s.remove(434234)   # Throws an error

s.discard(42323)

print(s)
```

### Output

```text
{34, 23, 1, 3, 22}
{34, 3, 322, 22, 23, 32}
```

> **Note:** Since sets are **unordered**, the order of elements in the output may vary. For example, you may see:

```text
{1, 34, 3, 22, 23}
{32, 34, 3, 322, 22, 23}
```

This is completely normal.

---

### Note

## What are Set Methods?

**Set methods** are built-in functions that allow you to add, remove, update, and perform operations on sets.

Since sets are **mutable**, these methods modify the original set.

---

## Initial Set

```python
s = {34, 23, 1, 3, 22}
```

Initially:

```text
{34, 23, 1, 3, 22}
```

---

## `add()` Method

```python
s.add(32)
```

Adds a new element to the set.

After:

```text
{34, 23, 1, 3, 22, 32}
```

Adding another element:

```python
s.add(322)
```

Now:

```text
{34, 23, 1, 3, 22, 32, 322}
```

If the element already exists, nothing changes.

Example:

```python
s.add(23)
```

The set remains unchanged because `23` is already present.

---

## `remove()` Method

```python
s.remove(1)
```

Removes the specified element.

Before:

```text
{34, 23, 1, 3, 22, 32, 322}
```

After:

```text
{34, 23, 3, 22, 32, 322}
```

### If the element is not present

```python
s.remove(100)
```

Output:

```text
KeyError: 100
```

This is why the following line is commented:

```python
# s.remove(434234)
```

because it would raise a `KeyError`.

---

## `discard()` Method

```python
s.discard(42323)
```

The element `42323` is **not** in the set.

Unlike `remove()`, `discard()` **does not raise an error** if the element is missing.

The set remains unchanged.

---

## Difference Between `remove()` and `discard()`

| `remove()` | `discard()` |
|-------------|-------------|
| Removes an element | Removes an element |
| Raises `KeyError` if element is missing | Does nothing if element is missing |
| Use when the element must exist | Use when you're unsure whether the element exists |

Example:

```python
s = {1, 2, 3}

s.remove(4)
```

Output:

```text
KeyError: 4
```

Using `discard()`:

```python
s = {1, 2, 3}

s.discard(4)

print(s)
```

Output:

```text
{1, 2, 3}
```

---

## Other Common Set Methods

| Method | Description |
|---------|-------------|
| `add(x)` | Adds an element |
| `remove(x)` | Removes an element; raises `KeyError` if missing |
| `discard(x)` | Removes an element if present |
| `pop()` | Removes and returns a random element |
| `clear()` | Removes all elements |
| `copy()` | Returns a shallow copy of the set |
| `update(iterable)` | Adds all elements from another iterable |

---

## Example: `pop()`

```python
s = {10, 20, 30}

x = s.pop()

print(x)
print(s)
```

Output (may vary):

```text
10
{20, 30}
```

Since sets are unordered, `pop()` removes an **arbitrary** element.

---

## Summary

- Sets are **unordered** and **mutable** collections of unique elements.
- `add()` inserts a new element.
- `remove()` deletes an element but raises a `KeyError` if it is absent.
- `discard()` deletes an element if present and does nothing otherwise.
- The order of elements in a set is **not guaranteed**.

### Final Output

```text
{34, 23, 1, 3, 22}
{34, 3, 322, 22, 23, 32}
```
